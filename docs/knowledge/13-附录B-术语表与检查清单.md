# 13 - 附录 B：术语表与检查清单

> [!abstract] 用法
> 前半是术语速查（新人 30 分钟建立词汇）；后半是五个阶段的可打印 Checklist，直接用于 [[11-模板-VLA项目实施手册]] 各阶段 DoD 核对。

## 1 术语表

| 术语 | 含义 |
| --- | --- |
| VLA | Vision-Language-Action：视觉+语言输入、动作输出的端到端策略模型 |
| VLM | Vision-Language Model：视觉-语言模型（VLA 的骨干） |
| 世界模型 World Model | 学习环境转移 p(s'|s,a)，用于想象/规划，2026 与 VLA 融合 |
| 策略 Policy | π(a|o,ℓ)：从观测与指令到动作的映射 |
| 动作块 Action Chunk | 一次预测的未来 H 步动作序列 |
| Chunk 长度 H | 动作块步数，典型 8–100 |
| 滚动时域 Receding Horizon | 每步重推理、只执行块内第 1 步的执行模式 |
| 时间集成 Temporal Ensemble | 多块重叠区按指数权重融合（ACT） |
| 行为克隆 BC | 模仿学习：直接拟合演示动作 |
| 遥操作 Teleoperation | 人工通过主从臂/VR 采集演示 |
| 本体感知 Proprioception | 机器人自身状态：关节角/末端位姿/夹爪 |
| EEF | End-Effector 末端执行器 |
| Delta 动作 | 目标=当前值+增量（区别于绝对位置） |
| 轴角 / 四元数 / 欧拉角 | 三种旋转表示，互转必须测试 |
| 归一化 Normalization | 动作/状态缩放到统一区间；OXE 惯例 q01/q99 分位数 |
| 离散动作 token | 动作每维切 256 桶映射为"词"（RT-2/OpenVLA） |
| FAST | π0 系的 DCT 动作 tokenizer，高分辨率离散化 |
| Flow Matching | 学速度场把噪声流到动作分布的生成式动作头（π0） |
| Diffusion Policy | 用扩散模型表示动作分布的策略 |
| ACT | Action Chunking Transformer（CVAE+chunk 的模仿学习基线） |
| Diffusion Policy | 同上，扩散头版本；两者是"是否用 VLA"的基线对手 |
| 双系统 System 1/2 | 快动作系统 + 慢推理系统的分层架构（GR00T/Helix） |
| Embodied CoT | 具身思维链：动作前生成显式推理中间表示 |
| 知识隔离 Knowledge Insulation | π0.5：保护 VLM 通用知识不被动作梯度破坏的训练法 |
| 共训练 Co-training | 机器人数据与图文数据混训防遗忘 |
| 灾难性遗忘 | 微调新任务导致旧能力丢失 |
| LoRA / PEFT | 低秩适配微调；r=16–64 常用 |
| EMA | 指数滑动平均权重，评估/部署常用 |
| OXE | Open X-Embodiment：22 种本体、100 万+ 轨迹的开放数据集 |
| LeRobot | HuggingFace 机器人栈：数据格式 v2 + SO 臂 + SmolVLA |
| openpi | Physical Intelligence 开源的 π0/π0.5 训练部署栈 |
| OpenVLA-OFT | OpenVLA 优化微调配方：并行解码+连续头，快 25–50× |
| RLDS | OXE 生态的 TFDS 数据格式 |
| Sim2Real Gap | 仿真到真机的性能落差 |
| Wilson CI | 小样本成功率的置信区间，评估必报 |
| 看门狗 Watchdog | 推理超时/异常时触发保持或停止的机制 |
| 影子模式 Shadow Mode | 新模型只推理不执行，与线上比对 |
| 数据飞轮 | 现场失败数据→标注→再训练→更强版本的循环 |
| 四件套 | 模型权重+归一化统计+词表/提示模板+配置的同版本发布单元 |

## 2 检查清单

### 2.1 数据采集前
- [ ] 成功判据已唯一化并可自动判定
- [ ] 采集设备（主从臂/VR/相机）到位并完成时间同步验证
- [ ] 相机曝光/白平衡/分辨率锁定
- [ ] 多样性矩阵已排班（位姿/实例/光照/背景/措辞）
- [ ] 动作与状态维度、单位、坐标系、gripper 语义已成文

### 2.2 训练前
- [ ] 数据 QC 清单全绿（[[04-数据体系]] §7）
- [ ] norm_stats 已计算并确认合理（画分布图）
- [ ] train/val 按 episode 划分，无场景泄漏
- [ ] 提示模板定稿并入库
- [ ] 基座模型与依赖版本锁定；seed 固定

### 2.3 训练后
- [ ] ≥3 个 checkpoint 完成 rollout 对比
- [ ] val loss 与 rollout 成功率的变化趋势一致（否则按 [[09-易错知识点]] §7 排查）
- [ ] 四件套归档且能一键复现
- [ ] 实验记录表完整

### 2.4 部署前
- [ ] 延迟预算实测达标（P99）
- [ ] 安全测试规程全过（[[10-评估与安全]] §6）
- [ ] 影子模式 ≥1 周无异常
- [ ] 回滚演练完成；监控与报警生效
- [ ] 线上四件套版本与归档一致

### 2.5 上线后（每周）
- [ ] 成功率/干预率/P99 延迟趋势正常
- [ ] 安全拦截 Top 原因已归因
- [ ] 失败片段已回流标注（数据飞轮）
- [ ] 图像质量（脏镜头/丢帧）指标正常
- [ ] 版本台账无漂移（线上 = 台账）
