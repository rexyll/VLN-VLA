# 02 - 发展历程与主流模型

> [!abstract] 本章解决
> 这个领域从哪来、现在有哪些可用模型、各适合什么场景、2026 年往哪走。选型结论直接跳到 [[03-架构与技术选型]]。

## 1 时间线（2017 奠基 → 2026 融合期）

- **2017–2021 奠基期**：Transformer（2017）、ViT（2020）、CLIP（2021）——VLA 的三大组件前身；此期机器人学习以 BC-Z、VPT 等模仿学习为主，动作与语义尚未统一。
- **2022-12 · RT-1**（Google）：首个规模化真机通用策略。35M 参数，EfficientNet + FiLM，动作离散 token 化，3Hz；13 台机器人 17 个月采集 13 万条演示、700+ 任务， seen 任务成功率 97%。
- **2023-03 · PaLM-E**（Google）：562B 具身 VLM，证明了"具身数据反哺多模态推理"，但输出是规划文本而非底层动作。
- **2023-07 · RT-2**（Google）：把动作当作语言 token，PaliGemma/PaLI-X 级 VLM 共微调网络数据 + 机器人数据；**语义涌现**：符号理解、推理类任务成功率约为 RT-1 的 2 倍。确立"VLM + 动作 token"范式。
- **2023-10 · Open X-Embodiment（OXE）**：21 家机构、22 种机器人本体、100 万+ 轨迹的开放数据集联盟，跨具身训练成为可能。
- **2024-01 · Octo**（Berkeley 等）：开源通用策略（27M/93M），diffusion 动作头，消费级 GPU 可微调——"小模型 + 好数据"路线的代表。
- **2024-06 · OpenVLA**（Stanford 等）：7B（PaliGemma + DINOv2 双视觉塔），OXE 97 万条训练；参数比 RT-2-X 少 55% 而表现更好；**LoRA 微调单卡 4090 可做**，成为开源事实标准。
- **2024-10 · π0**（Physical Intelligence）：3.3B（PaliGemma 骨干 + flow matching 动作专家），50Hz 动作块，能做叠衣、收拾桌面等长时程灵巧任务；**flow matching 动作头**从此流行。RDT-1B（清华系，1.2B diffusion transformer，双臂）同期发布。
- **2025-02 · Helix**（Figure）：双系统 S1(7B VLM) + S2(80M 快策略)，人形**全身上半身**连续控制（手腕/躯干/头/手指），双机协作完成家庭任务。
- **2025-03/06 · GR00T N1 / N1.5**（NVIDIA）：首个开放人形基础模型（2B/3B），Eagle-2 VLM + DiT flow 动作头，跨具身，权重在 HuggingFace。
- **2025-02 · OpenVLA-OFT**（arXiv 2502.19645）：微调配方优化——并行解码 + 动作块 + 连续动作 + L1，推理提速 **25–50 倍**，精度同步提升；7B 模型 16–18GB 显存即可推理。
- **2025-04 · π0.5**（PI）：共训练异构任务 + **知识隔离（knowledge insulation）**，首次在**全新家庭**零预采下完成开放世界泛化；openpi 开源 π0/π0.5（含 FAST tokenizer）。
- **2025-06 · SmolVLA**（HuggingFace）：450M 社区级 VLA，LeRobot 生态，**异步推理**提速 30%、任务吞吐翻倍；配合 SO-101 低成本臂，把 VLA 门槛拉到消费级。
- **2025-09 · Gemini Robotics 1.5 / ER 1.5**（Google DeepMind）：**Embodied Thinking**（行动前显式思考）、从视频学习、跨具身迁移；ER 系列作为"高层大脑"输出规划与空间推理。
- **2026-01 · Helix 02**（Figure）：从上半身扩展到**全身**（行走 + 操作 + 平衡一体化）。
- **2026-03 · GR00T N2**（NVIDIA）：基于 DreamZero 研究的"**世界动作模型**"架构，世界模型与 VLA 融合路线的标志性产品。
- **2026-09 · π0.7**（PI）：主打**零样本任务泛化**——执行训练中从未见过的任务。
- **2026 学术趋势**：Embodied Chain-of-Thought（如 ZR-0，2.6B，具身思维链 + 密集监督）、潜空间思维链、World Model vs VLA 路线之争（结论日趋"融合"而非替代）。

## 3 开源生态速览

| 生态 | 内容 | 什么时候用 |
| --- | --- | --- |
| **LeRobot**（HuggingFace） | 数据格式 v2.x、SO-100/101 廉价臂、SmolVLA、ACT/DP 训练栈、异步推理 | 入门、教学、快速原型（首推） |
| **openpi**（Physical Intelligence） | π0/π0.5 权重 + JAX 训练/微调脚本 + FAST tokenizer | 灵巧操作、需要 50Hz flow 头 |
| **openvla / openvla-oft** | 7B VLA + OFT 微调配方（LoRA/全参） | 需要语言泛化强的单臂/双臂操作 |
| **Isaac GR00T**（NVIDIA） | GR00T N1.5 权重 + Isaac Lab/GR00T synthetic 数据管线 | 人形、仿真合成数据 |
| **OXE / DROID** | 跨具身大规模数据集 | 预训练 / 共训练数据源 |
| MuJoCo / Isaac Lab / ManiSkill | 仿真 | 数据增广与安全评估 |

## 4 按场景选模型的粗规则

| 你的处境 | 建议 |
| --- | --- |
| 学习/课程/原型，预算 < 1 万 | SO-101 + LeRobot + SmolVLA（或先 ACT/Diffusion Policy） |
| 单臂/双臂操作 + 需要语言泛化 | OpenVLA-OFT 微调（LoRA） |
| 高频灵巧任务（叠衣、插线） | π0 系（openpi）微调 |
| 人形/多本体 | GR00T N1.5 微调，或 Gemini Robotics 闭源 API |
| 数据 < 50 条演示、任务固定 | 先别用 VLA，用 ACT / Diffusion Policy（见 [[03-架构与技术选型]] 决策树） |
