# 00 - 总览与导航

> [!abstract] 本库定位
> 这是一套 **VLA（Vision-Language-Action，视觉-语言-动作模型）** 的完整知识库：从基本原理、发展历程、架构选型，到数据、训练、部署的业务全流程，配套可运行的实现代码、易错知识点清单，以及一套可直接套用的「VLA 项目实施模板」。
> 目标：**拿到任何一个现实场景，都能按本库的模板走完「调研 → 立项 → 数据 → 训练 → 评估 → 部署 → 运营」全过程。**

## 三条学习路线

> [!tip] 按目的选路线，不必顺序通读

**路线 A：先搞懂原理（约 1–2 天）**
`01 基本原理 → 02 发展历程 → 03 架构选型 → 13 术语表`

**路线 B：动手实现（约 1 周）**
`01 → 08 实现代码（跑通 mini_vla 全流程）→ 04 数据 → 05 训练 → 09 易错点`

**路线 C：落地一个真实项目（数周到数月）**
`03 选型 → 07 流程图 → 11 模板（复制并逐节填写）→ 04/05/06/10 按 P0–P6 推进 → 12 特殊场景对照`

## 本库约定

- 所有图均为 Mermaid，Obsidian 原生渲染；代码块为 Python。
- 引用关系使用 `[[wiki 链接]]`，复制整个文件夹到任意 Obsidian 库均可使用。
- 标注 ⭐ 的内容属于「模板骨架」，落地项目时直接复制改写。
- 时效性说明：模型进展截至 **2026-10**（π0.7、GR00T N2、Helix 02 等），框架 API 以官方仓库为准；遇到 API 变动以 [LeRobot](https://github.com/huggingface/lerobot)、[openpi](https://github.com/Physical-Intelligence/openpi)、[openvla-oft](https://github.com/moojink/openvla-oft) 官方文档为准。

> [!warning] 使用本库的第一原则
> VLA 不是万能药。任何项目开工前，先回答 [[03-架构与技术选型]] 的第一问：**这个场景到底适不适合 VLA？** 很多工业场景用 ACT/Diffusion Policy 或传统视觉伺服更便宜、更稳、更快。
